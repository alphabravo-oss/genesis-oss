# Tempo

Tempo stores traces. The default image is the public Grafana build.

| Image | Reference |
|---|---|
| Tempo | `docker.io/grafana/tempo:2.10.5` |

Upstream docs: [https://grafana.com/docs/tempo/latest/](https://grafana.com/docs/tempo/latest/)

Grafana has a Tempo datasource after the monitoring release is Ready.
